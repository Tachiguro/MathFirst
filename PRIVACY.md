# MathFirst Privacy Policy

**Effective date:** September 19, 2026
**Application:** MathFirst (`com.tachiguro.mathfirst`)
**Developer:** Tachiguro

## Overview

MathFirst is an offline mental arithmetic practice application developed by Tachiguro. MathFirst is designed to protect learner privacy by operating locally on your device without user accounts, advertising, analytics, or remote data collection.

## Data Collection and Transmission

- **No Personal Data Collection:** MathFirst does not collect personal data or sensitive user data for the developer.
- **No Remote Inspection:** The developer does not remotely collect, inspect, or monitor learner progress or attempt history because the application contains no network or data-upload mechanism.
- **No Data Transmission:** MathFirst does not transmit learner data to the developer.
- **No Third-Party Sharing or Sale:** MathFirst does not sell, rent, or share user data with third parties.
- **No Advertising, Analytics, or Tracking:** MathFirst does not contain advertising SDKs, analytics libraries, or tracking frameworks.
- **No Accounts or Cloud Sync:** MathFirst does not require user accounts, registration, or sign-in, and does not provide cloud synchronization.
- **No Network Permissions:** The Android release does not request Internet or network-state permissions (`android.permission.INTERNET`, `android.permission.ACCESS_NETWORK_STATE`).

## Local Data Storage and Retention

Learning progress, attempt history, and application preferences are stored locally on the device.

- **Retention:** Local data remains on the device until removed through the application reset functions, uninstallation, or affected by supported operating-system-managed device migration.
- **Cloud Backup:** Routine cloud backup of MathFirst learner data is restricted under the application's Android backup rules.

## Device-to-Device Transfer

On supported Android versions, operating system functionality may transfer authorized local learner database files directly during an authorized device-to-device migration. That device-to-device transfer is managed by the operating system and does not transmit learner data to the developer.

## Data Deletion and Reset Semantics

Learners can manage or remove locally stored data at any time through the in-app reset functions in Settings or by uninstalling the application:

- **Reset Learning Progress:** Clears local attempt history, item learning states, spaced-repetition cards, and operation progression while preserving UI language, appearance, keypad layout, enabled operations, and practice-time preferences.
- **Restore Default Settings:** Restores UI language, appearance, keypad layout (PC numpad default), enabled operations, and practice time to default settings while preserving all learning progress intact.
- **Full Local Reset (Reset All Application Data):** Clears all learning progress and resets all preferences (UI language, appearance, keypad layout, operations, practice time) to a fresh installation state.
- **Application Uninstall:** Uninstalling MathFirst removes the application and its local sandbox data from the device, subject to standard platform operating system behavior.

## In-App Privacy Information

Privacy information is directly accessible offline within the application via Settings (`/privacy`) in English, German, and Russian without requiring network connectivity.

## Changes to This Privacy Policy

Future versions of MathFirst that materially change data handling may require this privacy policy to be updated.
