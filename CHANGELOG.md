### Added
- Completed and merged MF-UX-002 through Pull Request #11: replaced static practice-gate titles with deterministic localized contextual copy for initial readiness, short and long returns, manual-pause resume, and background resume. The 55-message-per-locale English/German/Russian corpus uses stable language-independent IDs, bounded ordered repetition avoidance, and stable presentation across rerenders, navigation, and language changes; onboarding readiness wording is history-neutral. This presentation-only change introduced no learning-policy or Schema V5 change.
- Implemented and review-approved MF-UX-003 on candidate branch `feat/mf-ux-003-native-identity`: established canonical MathFirst application identity and version/build metadata; added localized Settings version/build display; replaced stock .NET icon and splash treatment with the native MathFirst geometric MF identity, adaptive icon, palette, and theme-aware host backgrounds; localized Not Found content; removed unused template identity payloads; and strengthened identity, metadata-parser, localization, SVG, native-host, and platform contract coverage. The package remains unmerged pending its governed documentation, validation, push, and Pull Request lifecycle.
- Accepted the MF-LEARN-001 documentation architecture for independent operation progression and an open-ended fact space in [ADR-0003](docs/decisions/ADR-0003-independent-operation-progression-and-open-ended-fact-space.md): defined the Hybrid dense/structured curriculum, unique acquisition ownership, deterministic representative frontiers, correctness-and-fluency advancement gates, operation/role interleaving, lazy fact materialization, stable FactIds, Schema V5 target state, and atomic V4 evidence migration without learner reset.
- Completed and merged MF-LEARN-001 through Pull Request #9: implemented Schema V5, independent operation progression, deterministic bounded selection, and the open-ended curriculum runtime; `REVIEW_APPROVED`, 409 Core tests passed with 0 failed and 0 skipped, Windows and Android Release builds completed with 0 warnings and 0 errors, and vulnerability and static-regression audits were clean before merge.
- Implemented and merged the Android V1 runtime and cross-platform foundation (`MF-AND-001`) through Pull Request #7: activated the MAUI app for Android alongside Windows; extracted the concrete Schema V4 SQLite store and `Microsoft.Data.Sqlite` package into `MathFirst.Infrastructure.Sqlite` while retaining persistence contracts in Application; kept Android learner data private under `FileSystem.AppDataDirectory\mathfirst_learner.db`; made the shared Phone/PC custom keypad the primary Android answer UI with Android-specific native soft-keyboard suppression intent and preserved external keyboard/Enter paths; derived monotonic answer timing from app foreground state, Practice surface activity, a coherent transient Ready/Pause/Background-Resume gate, and Awaiting Answer so background, lock, Settings, onboarding, pause, and feedback time cannot create hidden timeouts; added .NET 10 system-bar/cutout safe-area handling, responsive phone layouts, deterministic smart auto-submit, blocking accessible Incorrect/Timeout feedback, and lifecycle/reset/input coverage. The recorded real-device Android spot-check passed for responsive layout, custom keypad/native IME behavior, Ready/Pause/Resume, smart auto-submit, and Incorrect/Timeout feedback context.
- Implemented Windows UX and application-identity alignment (`MF-WIN-UX-001`): adopted the KnownFirst-centered Settings card language with a language dropdown, responsive appearance controls, neutral default-settings restoration, separated destructive reset cards, and post-render auto-scroll/focus for every inline reset confirmation; introduced a localized four-step onboarding flow (Welcome, Phone/PC keypad selection with previews, three-item tutorial explaining adaptive repetition and the non-pass/fail 12-task mixed round, Ready/Get Started) and an immediately applied Settings keypad card; added a persistent UI-only Phone-default / PC-numpad preference plus a centered responsive clickable/touchable Windows keypad; enforced canonical unsigned decimal input with both comma and period support, exact decimal equivalence, rejection of redundant leading zeros, a 28-character limit, and synchronous pre-DOM keyboard/paste blocking backed by authoritative C# validation so rejected input creates no semantic attempt; widened the responsive answer field for future larger results and allowed the equation/input regions to wrap without shrinking arithmetic typography; localized the user-facing checkpoint phase as `Mixed round`, `Mischrunde`, and `Смешанный раунд` with `n/12` context while preserving its progression logic; made Get Started the authoritative practice-timer activation gate so Settings and onboarding never consume answer time or create hidden timeout attempts; changed the production application identity to `com.tachiguro.mathfirst` with Windows runtime publisher `Tachiguro`, yielding the logical app-data root `%LOCALAPPDATA%\Tachiguro\com.tachiguro.mathfirst\Data` without migrating or deleting legacy development data; documented deferred Android native-IME/viewport/overlap validation; and added deterministic timing, input, keypad, reset, identity, UI-source, and localization contracts.
- Implemented Adaptive Millisecond Countdown Timer & Responsive Layout Hardening (`MF-IMPL-007`), introducing dynamic answer deadlines based on consecutive-correct streak (30s / 20s / 15s / 10s ladder) where incorrect answers or timeouts safely reset streak and restore the 30-second window, enlarging the full-card-width countdown progress bar to 40-48px height (`clamp(40px, 4.5vh, 48px)`) with centered prominent bold millisecond precision text (`clamp(1.25rem, 2.8vh, 1.65rem)`, `XX.XXX s`) rendered with a direct high-contrast black glyph outline (`-webkit-text-stroke: 2px #000`, `paint-order: stroke fill`) directly on the text for crystal-clear readability across all fill colors and themes, implementing monotonic pause/resume timing in `TrainingSession` across Settings navigation (preserving remaining deadline and excluding time spent in Settings from response latency and timeout evaluations), preserving completed feedback interaction states (`TimeoutFeedback`, `IncorrectFeedback`, `CorrectFeedback`) across view navigation without restarting timers or generating duplicate attempt records, re-aligning training page composition to top-justify MathFirst branding and Settings navigation, lowering primary action button placement, introducing portrait layout responsive rules with large arithmetic typography (`clamp(2.5rem, 6.5vw + 1.5vh, 4.75rem)`), adding developer diagnostics deadline telemetry localized in English, German, and Russian, and expanding test suite to 178 passing unit and simulation tests.
- Implemented Windows V1 Hardening & End-to-End Simulation (`MF-IMPL-006`), performing exhaustive validation of all 418 V1 arithmetic facts across Addition, Subtraction, Multiplication, and Division, executing complete deterministic end-to-end progression simulations (Level 1 introduction through Level 10 checkpoint and transition into open-ended adaptive mixed practice with zero level 11 expansion), conducting 5,000-attempt synthetic learner simulations across Strong, Mixed, and Struggling profiles verifying FSRS-6 numeric safety and task-time determinism, performing high-volume SQLite stress tests (5,000 atomic commits in isolated temp DB), verifying three-way reset semantics, auditing package dependencies (0 vulnerabilities), ensuring localization dictionary completeness across English, German, and Russian, verifying native Windows startup and restart persistence, and expanding test coverage to 150 passing unit and simulation tests.
- Implemented Final Responsive UI / UX Polish (`MF-IMPL-005`), eliminating double-shell nesting and phantom 1-10px scrollbars between `MainLayout.razor` and `Home.razor`, introducing fluid multi-dimensional responsive scaling across width (360px up to 2560px+) and height (300px up to 1440px+) with low-height adaptations (`@media (max-height: 560px)` and `@media (max-height: 500px)`), stabilizing feedback banner height to prevent vertical UI layout jumping, refining countdown timer contrast and linear depletion, restructuring Settings Developer Diagnostics into 4 visual groups (Learning Progression, Checkpoint Status, FSRS-6 Task Scheduler, Timing & Storage) with localized section headers and database path word-wrapping, polishing Danger Zone confirmation layouts and theme tokens, and verifying 140 passing automated tests.
- Implemented Checkpoint Mixed Practice and Progression Hardening (`MF-IMPL-004`), completing the full progression lifecycle around FSRS-6 task-based scheduling (Level $N$ Addition $\rightarrow$ Subtraction $\rightarrow$ Multiplication $\rightarrow$ Division introduction $\rightarrow$ Bounded Mixed Checkpoint of 12 accepted attempts $\rightarrow$ Level $N+1$ advance; terminating at Level 10 checkpoint and transitioning into open-ended adaptive mixed practice across all 418 facts without level 11 expansion), implementing repetition density and diversity rules (3-fact exact duplicate cooldown, 3-fact commutative mirror cooldown for Addition and Multiplication, non-commutative Subtraction and Division exemption, and 2-fact maximum operation streak diversity), upgrading SQLite persistence to Schema V4 with atomic checkpoint telemetry tracking (`completed_checkpoint_level`, `active_checkpoint_level`, `checkpoint_attempt_count`, `checkpoint_correct_count`) and lossless migrations from V3 and V1, adding training Checkpoint badge UI and Settings Diagnostics telemetry in English, German, and Russian, and expanding test suite to 140 passing automated unit tests.
- Implemented FSRS-6 Task-Based Scheduler Integration (`MF-IMPL-003`), integrating `FSRS.Core 1.0.7` to power long-term arithmetic spaced repetition scheduling over discrete practice task distance (1 accepted attempt = 1 virtual day elapsed from `2000-01-01T00:00:00Z`), implementing domain-independent `IFsrsScheduler` and `FsrsSchedulerAdapter` with 21 default parameters, `DesiredRetention = 0.95`, `EnableFuzzing = false`, empty learning steps, and `MaximumInterval = 36500`, implementing deterministic `FsrsRatingMapper` (Incorrect/Timeout -> Again, Correct > 2500ms -> Hard, Correct 1001..2500ms -> Good, Correct <= 1000ms -> Easy), upgrading SQLite learner database to Schema V3 with `practice_position` tracking and `fsrs_card_state` table with deterministic historical attempt replay migration, implementing 4-tier adaptive practice selection prioritizing same-session remediation and introduction turns before overdue FSRS reviews, adding FSRS diagnostics telemetry to Settings with English, German, and Russian localization, and expanding automated test coverage to 128 passing tests.
- Implemented Timed Training Outcome and Explicit Error Feedback (`MF-IMPL-002`), adding a visible 30-second countdown answer timer with right-to-left scaleX depletion and smooth green-to-red color transition, monotonic timeout evaluation, explicit incorrect and timeout feedback showing the submitted answer and correct result with required acknowledgement (Enter or Continue), lossless transactional SQLite schema migration from V1 to V2 supporting nullable submitted answers and explicit `AttemptOutcome`, and expanding automated test coverage to 97 passing tests.
- Implemented complete Windows-First V1 Learning Core (`MF-IMPL-001`), featuring independent per-operation range progression (Addition, Subtraction, Multiplication, Division each maintaining independent operand ranges `0..M_op`), exposure-based staircase turn sequencing (`+ -> - -> × -> ÷ -> + next range`), non-blocking range expansion during wrong-answer remediation, debounced event submission and advancement, human-friendly response latency measurement (`XXX ms` / `X.XX s`) with explicit `Fluent` / `Slow` classifications, SQLite native persistence adapter with ADR-0002 compliance, Developer diagnostics telemetry (per-operation ranges, turn, remaining unexposed facts, mastered breakdown, accuracy, latency, schema revision), Danger Zone 3-way testing resets, fluid responsive UI scaling across narrow portrait, short landscape, and wide desktop viewports, and 85 passing automated unit tests.
