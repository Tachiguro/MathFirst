## [Unreleased]

### Added
- Added MF-SET-001 practice configuration and onboarding enhancements: choose any non-empty subset of Addition, Subtraction, Multiplication, and Division in Settings or during fresh-install onboarding (all four enabled by default, using shared preferences without duplicate models); disabled operations disappear from new practice turns and the progress HUD while retaining full learning progress for later resumption. Added a returning learner progress presentation before practice start displaying only enabled operations without invented mastery percentages. Settings changes keep the current exercise stable and apply to the next exercise. Session check-ins at 20-attempt boundaries summarize completed attempts, correct count, median correct latency, and actual Stage changes across process-local segments. Practice Time offers Standard, 30 s, 45 s, and 60 s applying as a minimum deadline floor; Pause, Settings, and same-process background time freeze the active answer timer, while a cold start resets only the in-flight timer without losing preferences or learner data. Removed developer Statistics / Diagnostics from Settings without deleting learner history or scheduling data. Established strict answer input lifecycle invariants preserving unsubmitted partial input on the same exercise through pause/settings/background transitions while guaranteeing a fresh, empty input buffer for every new exercise via process-local `FactInstanceRevision`, `CurrentAnswerInput`, and input element re-keying, resolving a physical Android input retention defect after session check-in breaks (`f453501412b7c9fce39356a0837a5b862d6221fd`). Three-way reset semantics distinguish Reset Learning Progress (clears progress, preserves preferences), Restore Default Settings (restores UI/practice defaults, preserves progress), and Full Local Reset (clears both). Verified with 1037 Core tests passing, clean Windows/Android Release builds (0 warnings / 0 errors), and successful user validation on a physical Android device using debug validation APK `MathFirst-MF-SET-001-f453501-debug.apk` (SHA-256 `97f85e448d078e46d813aa1244e49b95933e51e1c9d64732faf3a614ae31db12`). Staging, commit, push, Pull Request, merge, and production release operations remain separate downstream lifecycle steps.
