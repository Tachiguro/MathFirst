- **Historical MF-CYBER-007 Mechanics (merged PR #91)**:
  - **Critical Strike** is accuracy-based, independent of speed, latency, and pace calibration. Rank 1: Level 12, 6 SP, every fifth confirmed correct combat attack +50%; Rank 2: Level 50, 12 SP, every fourth +100%. Rank 0 is disabled. Only purchased-rank correct attacks count; incorrect answers preserve the Critical counter. Critical rank purchases restart its phase; game-over and reset clear run counters.
  - **Overdrive** Rank 1: Level 20, 5 SP, five consecutive correct combat answers arm +50% damage for the next two attacks. Rank 2: Level 80, 10 SP, four consecutive correct answers; accepted DEC-007-04 retains +50% / two attacks. The triggering answer does not receive its newly armed bonus. A trigger resets the streak to zero; later correct attacks build the next streak without overlapping windows. Any incorrect answer resets the streak and cancels remaining bonus attacks, including when Firewall absorbs all counter-damage. Rank 0 banks no progress (OD-1); Rank 1 to Rank 2 preserves the earned Overdrive streak.
  - **Damage and entitlement**: bonuses stack additively with one final ceiling, `ceil(baseDamage * (100 + criticalBonusPercent + overdriveBonusPercent) / 100)`, using exact integer arithmetic and checked overflow. Attack damage and modifier ranks bind to the presented question (`FactInstanceRevision`); purchases do not upgrade an in-flight question. Critical feedback reads immutable receipt bonus evidence, not a timer.
